# Accessibility acceptance criteria

- Keyboard-only users can reach and operate every action.
- Focus is always visible.
- Dialog focus is contained and restored.
- Text and controls remain usable at 200% browser zoom.
- Color contrast is checked in both themes.
- Status changes are announced with an appropriate live region.
- Motion can be reduced through the operating system preference.
- Touch targets are at least 44×44px where practical.
- Form inputs have labels, useful autocomplete values, and clear errors.
- Images have meaningful alt text or are explicitly decorative.
